# Shieldwall web

Browser-only plates and armor meter. Same statuses as the CLI: intact, scored, broken, unknown. Meter: intact 20, scored 10, broken 0, unknown 0. Label steel, bone, or blood.

Author: synthalorian  
License: Apache-2.0

## Open

Open `index.html` in a browser. Or serve this folder as static files and open the index. The page does not need a server.

## Privacy

Runs in your browser. Nothing leaves this page. Paste is not uploaded. There are no analytics, no external fonts, and no network requests.

Plate coverage, not a security guarantee.

An empty box is unknown, the same as a missing tool. The secrets box shows rule id and line number only, never the matched value.
